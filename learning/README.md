# Learning And Distillation

This folder defines Curo's post-execution learning process. Learning utilities
may analyze observability, provenance, replay, and review evidence and propose
reusable improvements. They do not have authority to promote those proposals.

## Files

- [`learning-distillation-protocol.md`](learning-distillation-protocol.md) - lifecycle, ownership, and promotion gates.
- [`learning-candidate-template.yaml`](learning-candidate-template.yaml) - proposal record.
- [`promotion-record-template.yaml`](promotion-record-template.yaml) - validated promotion record.

Observability links runs to candidates. The harness and evaluation pipeline
validate them. HITL approval is required for canonical Curo changes.
