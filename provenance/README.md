# Provenance

This folder contains examples and trace-oriented material for evidence produced by the harness.

## Files

- [`sample-provenance-record.yaml`](sample-provenance-record.yaml) - example record aligned with the provenance schema.

## Ownership

Provenance is established from observed inputs, outputs, validators, environment data, and tool events. The harness writes authoritative records. Missing provenance is represented as `UNKNOWN`; it is never invented by a model or reviewer.
