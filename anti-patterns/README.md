# Anti-Patterns

This folder catalogs recurring ways an AI-assisted workflow can appear compliant while bypassing ownership, validation, or provenance requirements.

## Files

- [`anti-patterns.md`](anti-patterns.md) - catalog of prohibited or high-risk patterns and their controls.

## Change rule

Add an anti-pattern when a failure mode has a concrete counterexample and an enforceable detection or prevention rule. Link the new entry to the owning policy and harness control where one exists.
