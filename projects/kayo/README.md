# KAYO project profile

KAYO is represented here as the coordination and governance layer associated
with the Second Brain platform. This profile preserves the authority boundary:

- Second Brain = KNOW
- KAYO = COORDINATE
- Control Room = OBSERVE
- Visual Data Node = UNDERSTAND
- Executor = ACT
- Validator = ESTABLISH EVIDENCE
- Human = AUTHORIZE

The assignment manifest defines distinct Strategist, Builder,
Critic/Reviewer, Deterministic Validator, Local/Private Model Lane, and Human
Approver roles. It does not assert that any provider, model, transport, or
external project root is currently available. Those decisions remain open and
must be approved by the human requester. Actual identity must be supplied by
observed run evidence.
