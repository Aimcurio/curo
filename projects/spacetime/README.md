This directory adds a current Curo project profile without reinterpreting the
legacy learning record as present intent or runtime truth.

`evidence/spacetime-sim-learning-record.json` is a byte-identical copy of
`manifests/spacetime-sim-learning-record.json`. Its SHA-256 is
`ec0d0eb61854d39d5ea3343ace6cd085182a11043e3b7eb7889a9f23335cb5ca`.
The original remains at its old path. The relocation record therefore uses
`COPY_PRESERVE_SOURCE` and preserves the old-to-new evidence chain.

The historical record establishes `E:\spacetime` as the recorded target at that
time and reports earlier build results. It does not establish current status,
provider/model availability, or observed identity. Those remain unresolved.
